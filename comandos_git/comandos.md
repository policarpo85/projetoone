## Criar uma branch nova

git branch nome-da-branch

## Ver as branchs existentes no projeto

git branch

## Mudar de uma branch para a outra branch

git checkout nome-da-branch

## Atualizar meu repositorio local (branch atual)

git pull

## Atualizar meu repositorio local (repositoria inteiro)

git fetch

## Ver arquivos na stage (prontos para subir)

git status

## Adicionar arquivo novos na stage (para subir)

git add nome-do-arquivo

ou

git add .

## Commitar um arquivo preparando para subir

git commit -m "mensagem adequada"

## Subir seus arquivos modificados para o repotorio remoto

git push origin nomda-da-branch
